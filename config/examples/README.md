# Configuration workspace

Develop Kopernicus and Kerbal Konstructs configuration here before promoting tested files to
`GameData/SoysGrandLandmarks/Configs`.

Do not put an enabled placeholder `.cfg` in `GameData`: ModuleManager and Kopernicus will try to
load every such file. Add the first runtime configuration only after its target coordinates,
heightmap path, and dependency syntax have been tested in the development KSP copy.
